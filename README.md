# Even or Odd Number Checker

## Description
A simple JavaScript program that checks whether a given number is even or odd using an if-else statement.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Checks even and odd numbers.
- Uses variables and if-else conditions.
- Displays results using console.log().

## How to Run
1. Open `index.html` in your browser.
2. Open the browser console (F12).
3. View the output.
